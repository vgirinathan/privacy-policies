LiteExcel · Privacy Policy

What happens to your spreadsheets, in plain terms

LiteExcel is a local, offline Excel/CSV viewer and editor. This page explains exactly what the app does — and does not — do with your data.

The short version

  • LiteExcel has no account, no sign-in, and no server. It runs entirely on your device.
  • The spreadsheets you open never leave your phone — there's nowhere for LiteExcel to send them, even if it wanted to.
  • No analytics or tracking SDK is active in this version of the app.
  • Advertising is present in the code but switched off for this release. If a future update turns it on, this policy and the Play Store listing will be updated first — see §4.

§1 Your files

When you tap "Open File" or "Create Excel," Android's own file picker (the Storage Access Framework) hands LiteExcel a reference to exactly one file — the one you chose. LiteExcel never scans your device's storage, never lists files you haven't opened, and never uploads a file anywhere. Reading, editing, and saving all happen through standard Android file APIs, on-device.

Files you open through "Share" or "Open with" from another app (e.g. your file manager or email client) are handled the same way — LiteExcel only ever touches the specific file the operating system hands it.

§2 App preferences

LiteExcel remembers a few things locally, using Android's on-device DataStore — nothing here is transmitted anywhere:

  • Recent files — file names and locations you've opened, so they show up on the Home screen.
  • Favorites — files you've pinned.
  • App settings — theme (light/dark/system) and display preferences.

This data lives only in LiteExcel's private app storage. It's removed automatically if you clear the app's storage or uninstall it.

§3 Permissions

PermissionWhat it's for
INTERNET Reserved for the optional advertising feature described in §4. Not used for anything else, and makes no network calls while ads are disabled.
ACCESS_NETWORK_STATE Same as above — lets the (currently disabled) ad SDK check connectivity before requesting an ad.

File access itself isn't a runtime "permission" in the Android sense — it's granted per-file, per-open, through the system file picker described in §1, and can't be used to reach any file you haven't explicitly selected.

§4 Advertising

LiteExcel is built to optionally show ads via Google AdMob to help support development, using Google's User Messaging Platform (UMP) for consent where required by law (e.g. GDPR in the EEA/UK). In this release, advertising is switched off entirely — the ad SDK never initializes and no ad-related network request is ever made.

If a future update enables ads, AdMob's own data collection (which can include an advertising identifier, coarse location, and device information, depending on your consent choices) would apply at that point — governed by Google's Privacy Policy. This page and the Play Store listing will be updated to reflect that before it ships, not after.

§5 Children's privacy

LiteExcel is a general-audience productivity tool, not directed at children under 13, and doesn't knowingly collect personal information from anyone — children included, since it doesn't collect personal information from any user in the first place.

§6 Retention & deletion

Since LiteExcel doesn't collect or store your data anywhere but your own device, there's nothing on a server for us to retain or delete. Everything described in §2 stays in the app's local storage until you clear it yourself — via the app's own controls, Android's Settings → Apps → Storage screen, or by uninstalling LiteExcel.

§7 Changes to this policy

If this policy changes, the "Effective" date at the top of this page will be updated. For any change that meaningfully affects what data LiteExcel handles — most notably, enabling advertising per §4 — we'll note it in the app's Play Store release notes as well.
